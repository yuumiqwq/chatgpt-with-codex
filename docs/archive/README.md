# Historical design archive

Files under this directory describe earlier Engineering Bridge releases and implementation plans. Their tool names, permission fields and workflow rules are retained as historical evidence only. They are not current API or architecture documentation.

Use the repository root README, [current tools](../tools.md), [architecture](../architecture.md), [work management](../work-management.md) and [security behavior](../../SECURITY.md) for chatgpt-with-codex today. Historical paths may refer to files that existed only at the recorded commit; those references are not instructions to restore retired interfaces.

The source repository retains these plans for maintenance history. Distributed packages include this index but omit the old plans; browse the [repository archive](https://github.com/yuumiqwq/chatgpt-with-codex/tree/main/docs/archive) when that history is needed.
